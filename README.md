# SWYNEX Sales Performance Analysis

## Project Overview
This project presents an end-to-end sales data analysis for SWYNEX. The project covers data cleaning, exploratory data analysis, business insights, and an interactive Power BI dashboard.

## Problem Statement
The objective is to analyze sales data and identify meaningful patterns in revenue, products, customers, countries, order status, and sales performance.

## Dataset
The project uses a sales orders dataset containing customer, product, pricing, quantity, date, country, and order-status information.

## Data Cleaning
The data was cleaned using Python and Pandas. The cleaning process included:
- Removing duplicate records
- Handling duplicate Order IDs
- Handling missing values
- Cleaning price and quantity fields
- Standardizing dates
- Standardizing customer and email information
- Standardizing gender, country, and order-status values

## Exploratory Data Analysis
Exploratory analysis was performed using Python and Excel to understand:
- Revenue performance
- Product category performance
- Country-wise sales
- Order status distribution
- Year-wise sales trends
- Quantity and price relationships
- Potential anomalies in the dataset

## Power BI Dashboard
An interactive Power BI dashboard was developed to visualize sales performance and provide business-focused insights.
